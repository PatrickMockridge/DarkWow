# tau

Anonymous peer-to-peer task manager. Distributed task scheduling and execution
over the DarkWow P2P network. Supports privacy-preserving task orchestration
for relayers, indexers, and other infrastructure services.

## Building

```shell
make
```

## Usage

```shell
./target/release/taud --help
```
