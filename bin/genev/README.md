# genev

Genesis Event Viewer. Tool for inspecting genesis block parameters, verifying
genesis deployment, and auditing contract initialization state. Part of the
DarkWow genesis ceremony infrastructure.

## Building

```shell
make
```

## Usage

```shell
./target/release/genevd --help
```
