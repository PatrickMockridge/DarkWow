# Security policy

Report vulnerabilities privately through GitHub's **private vulnerability reporting** on this
repository (Security tab → "Report a vulnerability"). Do not open a public issue for a suspected
vulnerability.

The full policy — scope, response targets, coordinated disclosure and safe harbor — is
[`doc/src/arch/disclosure-policy.md`](doc/src/arch/disclosure-policy.md).

Known open items are tracked in
[`doc/src/arch/verification-hazop.md`](doc/src/arch/verification-hazop.md).
