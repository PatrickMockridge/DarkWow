# Adjudications for `scripts/check-codec-size-derivation.sh` — the rule that a fixed-size composite
# derives its `ENCODED_SIZE` instead of restating the total as a lone integer.
#
# Format, one entry per line:
#
#   <rel path> : <type name> : <reason citing the mechanism>
#
# Content-keyed on path and type — NOT on line numbers — so a file that shifts underneath an entry
# keeps its adjudication, the choice every sibling checker made and for the same reason. A declared
# entry that no longer matches a finding is reported by the checker, so this list cannot outlive its
# sites.
#
# THE LIST IS A RATCHET, NOT AN AMNESTY. Every entry is a fixed-size composite whose `ENCODED_SIZE`
# is a single bare integer, and each one is either (a) a total that has already gone stale — the
# defect class `OBL-C150` records, which `PayInterestUpdateV1` is the demonstration of — or (b) a
# site deliberately kept as a lone integer with a reason that says why. "Unclear" is neither column.
#
# ADJUDICATED 2026-10-08 — all 21 sites read and summed from their own `encode` bodies; the gate is
# now **BLOCKING**. Every entry is column (b): a total deliberately kept as a lone integer, with the
# sum it equals named as the reason. The class is real — `PayInterestUpdateV1` carried 625 while its
# `encode` wrote 753 — and each of these is that shape *not yet stale*, which is why this is a ratchet
# and not a defect log. A new lone-integer composite now fails the build.
#
# Each reason states the sum, because the sum IS the adjudication. A nested type named in a reason
# contributes that type's own `ENCODED_SIZE`; `32` is a `pallas::Base`/`PublicKey`/`[u8;32]`, `8` a
# `u64`, `4` a `u32`, `1` a `bool` or a one-byte enum discriminant.
#
# WHEN ONE STOPS BEING TRUE, the gate says so: the sum in a reason is prose, so the check is a reader's
# or a run's — but a site whose `ENCODED_SIZE` goes stale is exactly what flagged it here, and the
# endpoint behind it is what made `PayInterestUpdateV1` visible.
