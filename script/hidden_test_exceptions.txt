# Hidden-test declarations — the reviewed list for `scripts/check-hidden-tests.sh` (OBL-C76)
#
# Format:  <rel path> :: <test fn or test module> : <reason, and how to run it>
#
# WHAT BELONGS HERE. A test that does not run in its crate's default configuration, with the
# reason it is that way and the command that does run it. The second half is not optional: the
# point of the list is that a reader can find out what a default run does not cover, and a claim
# that names neither the command nor the feature set is what OBL-C76 is about.
#
# WHAT DOES NOT BELONG HERE. A test that runs by default. When one of these is fixed — the feature
# made default, or the gate in front of it removed — its line comes out in the same commit, and the
# gate reports a stale entry so it cannot linger.
#
# THE ROOT CAUSE, in one line each. `src/linear/Cargo.toml` and `src/sdk/Cargo.toml` both declare
# `default = []`, and the features that carry these tests are enabled explicitly by their consumers
# (`bin/dwowd` enables `pow`, for instance). So a bare `cargo test -p dwow_chain --lib` lists 172
# tests where `--all-features` lists 263, and the 91 that differ are the consensus surface — the
# exact area this register's campaign works on.
#
# THE ROOT-CAUSE FIX EXISTS AND IS NOT TAKEN, deliberately. `default = ["pow"]` (and `["json"]` for
# the sdk) would make the bare ad-hoc command complete, which is the honest repair. It is not taken
# here because a default feature propagates to every consumer of the crate, so it changes the
# dependency graph and the build of crates that have no interest in PoW — a design decision rather
# than a patch, and one that belongs with whoever owns the crate's feature layout. Until it is
# taken, this list is the mechanism: the hidden set is enumerated on every run of the gate, and a
# new hidden test fails rather than quietly reducing what a pass count means.
#
# `make test` is unaffected by all of this — it runs `--release --all-features --workspace`, so the
# gates always exercised the full 263. The risk these entries exist for is the ad-hoc command.
