# Adjudications for `scripts/check-doc-code-paths.sh` — the rule that a backticked path citation in
# `doc/src` is a claim about the tree.
#
# Format, one entry per line:
#
#   <cited path> : <reason naming the OBL/F row or the mechanism that makes the absence the point>
#
# Keyed on the path, not the document or line, so a finding reported from several documents keeps one
# adjudication. A declared path that now resolves, or that no document cites any more, is reported as
# a **stale exception** (the gate's `stale` branch), so this list cannot outlive its sites.
#
# This list is for citations whose subject IS the absence — a dated audit, a row recording a
# deliberately removed module, a corrected note saying "this path does not exist", or an explicitly
# crate-relative shorthand. It is not for a stale claim: `doc/src/localnet-dev.md:50` was one and was
# fixed to `bin/dwowd/dwowd_config.toml` on 2026-10-21; the same path is still cited at line 20 as a
# negative note, which is why it appears below.
#
# Register row: OBL-C149 / OBL-T7.
