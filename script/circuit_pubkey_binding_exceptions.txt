# Format:  <zk source path> : <the equality as it appears in the source> : <reason, citing a register ID>

# The key is the *content* of the equality, not a line number, so an edit above a site moves
# nothing. The gate prints a matching finding as EXCEPTED with the reason below and exits 0; every
# other finding still exits 1.
#
# WHAT BELONGS HERE. A finding whose two sides have been read — circuit *and* host, in one command,
# which is the bar OBL-Z18 set — and whose reason names the mechanism that makes it sound, or the
# register row that schedules the repair. An entry that schedules a defect says so in those words.
#
# WHAT DOES NOT BELONG HERE. A site nobody has read. This rule matters for this file specifically:
# the detector is deliberately *shallow* — it treats a value as seen only when it is a literal, a
# named constant, or a `constrain_instance` target — because it cannot see a host, and OBL-Z18's
# adjudication is the record of that gap being closed by reading. Growing this list is the act of
# adjudicating; an entry whose justification was inferred from a name is exactly the Orchard-class
# bug wearing an audit badge.
#
# WHY THE GATE IS SHALLOW RATHER THAN SMART. A refined classifier — propagating "consumed by an
# exposed determination" back through a hash to its arguments — would cut this list from 57 to 15.
# It is not done, because that propagation is a claim about crypto binding that a line-anchored
# script cannot establish, and a gate that *silently* classifies a genuine vacuity as bound is worse
# than one that reports 57 candidates a reviewer must read. The sibling gate,
# `check-circuit-instance-derivation.sh`, does make that claim (it classifies such a value
# `redundant`); this one deliberately does not, and the reasons below are the difference.
