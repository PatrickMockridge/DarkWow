# Adjudications for `scripts/check-circuit-tx-pair-last.sh` — the rule that a circuit's last
# two `constrain_instance` targets are `tx_binding` then `tx_nonce`.
#
# Format, one entry per line:
#
#   <rel path> : <circuit> : <reason citing the mechanism, the host read, or a register ID>
#
# Content-keyed on path and circuit name, NOT on line numbers, so a file that shifts
# underneath an entry keeps its adjudication — the same choice
# `circuit_pubkey_binding_exceptions.txt` and `circuit_dead_value_exceptions.txt` made, and
# for the same reason. A stale entry is reported by the checker so this list cannot outlive
# its sites.
#
# THE LIST IS A RATCHET, NOT AN AMNESTY. Every entry here is a circuit with the pair in the
# wrong place, and every one of them is scheduled for the same repair: move
# `constrain_instance(tx_binding); constrain_instance(tx_nonce);` to the end. Ten were
# repaired in the first pass (`box`, `multisig`, `betting_stake`, `purse`, `otc_swap`,
# `native_token` x3, plus the verdict reorders) and each deletion from this file should
# follow the same unit of work.
#
# WHY THE REPAIR IS PER CONTRACT AND NOT A SWEEP. Moving an instance renumbers three
# vectors that must agree element for element: the circuit's `constrain_instance` order, the
# `get_metadata` arm's push order, and the client's `to_public_inputs`/`to_vec`. Reordering
# the circuit alone yields a proof that fails verification, and
# `scripts/check-circuit-metadata-alignment.sh` is the instrument that says so — it compares
# counts as a PASS and order as a WARN. `OBL-C198` is the register row for the campaign.
#
# EVERY NON-CONFORMING CIRCUIT IN THE TREE IS LISTED. Measured 2026-10-04 over 166 circuits:
# 136 conform, 30 have the pair elsewhere in the vector, and 1 (`bearer_bond`'s
# `ProveCoverage_V2`) has no pair at all. There is no fourth category, so this file is the
# complete census — a circuit that conforms today and is edited into the middle shape fails
# the check, which is the point.
#
# REPAIRED SINCE, each deleted with its own unit: `darktoshi_dice/settle_bet` on 2026-10-05
# (the circuit, its arm, its client and its spec in one commit, `233d585434`). The deletion
# came a commit late, which is worth recording because the instrument caught it and a reader
# should know the report works: `--self-test` proves the checker can find a middle pair, but
# the *stale* half only prints on a full run with `ALL=1`, and the migration was committed
# after a run without it. Two more lines — `bearer_bond`'s `prove_coverage` and `redeem` —
# belong to that contract's session and go with its own unit.
