# Developer Study Guide

This is a self-directed study guide for developers who want to understand
the foundations of cryptographic protocol design. Cryptocurrency sits at
the intersection of economics, cryptography, and distributed systems.

## Methodology

We recommend a mentorship-based approach to learning. Participants are
self-directed but can consult more experienced mentors when stuck. Learning
through dialogue is encouraged — it builds stronger understanding and
connections within the community.

Leaders should develop both strategic knowledge (macro analysis) and
technical skills (direct implementation). Theory without practice gathers
dust; practice without theory is undirected.

## Getting Started

1. Install a Linux operating system (Ubuntu or Manjaro recommended).
2. Learn Python — [Python Crash Course](https://agorism.dev/book/python/Eric%20Matthes%20-%20Python%20Crash%20Course%20A%20Hands-On%2C%20Project-Based%20Introduction%20to%20Programming%20%282016%2C%20No%20Starch%20Press%29.pdf) is a good starting text.
3. Follow the [darkirc guide](../misc/darkirc/darkirc.md) to connect with the team.

*For historical context on the DarkFi/DarkWow fork, see the
[Books](books.md) page for Fisher, Land, and the Warwick CCRU collection.
This reading is optional — not a prerequisite for contributing code.*

## Branches

All branches take roughly 1-2 years to reach proficiency. After about
6 months, participants can begin applying their knowledge to small,
practical tasks.

### Token Scientist

Token engineering uses Python to build simulations and economic models
of incentive mechanisms and liquidity flows.

1. Werner, *New Paradigm in Macroeconomics* — several months of study, strong basis for economics.
2. [Understanding Pure Mathematics](https://agorism.dev/book/math/intro/A.%20J.%20Sadler%2C%20D.W.S.Thorning%20-%20Understanding%20Pure%20Mathematics%20%281987%2C%20Oxford%20Up%20Education%29.pdf) — or skip if you know maths well.
3. [DeFi and Token Engineering](https://agorism.dev/book/economy/Economics%20and%20Math%20of%20Token%20Engineering%20and%20DeFiV1.1.pdf).

### Software Developer

Software developers build the products that users interact with — turning
research into working code. Senior developers understand how computers work
at a deep level across architecture, operating systems, and networking.

1. Learn computer architecture, operating systems, and software architecture.
2. [The Rust Programming Language](https://doc.rust-lang.org/stable/book/).
3. [Install Arch Linux](https://wiki.archlinux.org/title/Installation_guide), learn the terminal.

### Cryptography Researcher

Cryptography researchers craft protocols that exploit the hard limits of
mathematics to create systems with provable properties. Requires strong
algebra background.

1. Pinter, [*A Book of Abstract Algebra*](https://agorism.dev/book/math/algebra/%28Dover%20Books%20on%20Mathematics%29%20Charles%20C%20Pinter%20-%20A%20Book%20of%20Abstract%20Algebra-Dover%20Publications%20%282010%29.pdf).
2. Prototype schemes using [SAGE](https://doc.sagemath.org/pdf/en/a_tour_of_sage/a_tour_of_sage.pdf).
3. Progress through increasingly complex cryptographic constructions.

### Protocol Engineer

Protocol engineers design blockchain consensus algorithms, P2P networks,
and distributed synchronization primitives. Combines theory (distributed
systems, algorithms) with practice (Rust networking code).

Requires strong computer science fundamentals, programming ability, and
sufficient algebra to understand the cryptographic primitives being
networked.
