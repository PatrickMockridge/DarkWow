# Ideology

DarkWow's ideology is inseparable from its technical architecture. See the [Philosophy](philosophy.md) page for the full articulation.

## Core Principles

1. **No Governance DAO — Pure PoW**: Consensus derives from work, not token-holder voting. This rejects the plutocratic premise of governance tokens.

2. **No Premine — Every Coin Mined**: The coin supply originates entirely from proof of work. No founder allocation, no VC tranche, no "fair launch" theater.

3. **Sovereignty Through Cryptography**: ZK proofs provide the technical substrate for sovereignty — the ability to prove a statement is true without revealing the underlying information.

4. **O-Cap Authorization**: Object capabilities replace access control lists. A holder of a capability token can exercise it without asking permission.
